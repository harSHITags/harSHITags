## Featured projects

### 🛍️ [Retail RAG Chatbot](https://github.com/harSHITags/Retail-RAG-Chatbot)
A retrieval-augmented QA service for retail documents. Uploaded files are chunked, embedded, and indexed in FAISS; at query time the most relevant passages are retrieved and passed to Gemini, so answers stay grounded in the source text. An optional research-agent mode (CrewAI, Groq, DuckDuckGo) handles questions the documents can't answer. The service is containerised with Docker and built through a GitHub Actions CI/CD pipeline. I replaced local Hugging Face embeddings with API-based embeddings to keep the container image lightweight.

`Python` `FastAPI` `LangChain` `FAISS` `Google Gemini API` `CrewAI` `Docker` `GitHub Actions`

### 📉 [Customer Churn Prediction](https://github.com/harSHITags/Customer-Churn-Prediction)
A churn analytics platform: an XGBoost model served through a FastAPI backend, with a React + TypeScript interface for running predictions. SHAP explanations show which features drive each prediction, so results are interpretable rather than a bare probability. Containerised with Docker.

`Python` `Scikit-learn` `XGBoost` `SHAP` `FastAPI` `React` `TypeScript` `Docker`

### 🗂️ [File Hider](https://github.com/harSHITags/File-Hider-Java-MySQL-)
A Java application with MySQL integration that implements file-hiding functionality, built to practise object-oriented design and database-backed persistence.

`Java` `MySQL`
